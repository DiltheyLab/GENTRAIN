# Getting Started

You can find the Gentrain Github Repository at https://github.com/DiltheyLab/GENTRAIN.

## Installation

## Build GENTRAIN Docs locally on linux or MacOS

```console
sh docs.sh
```

## Build GENTRAIN Docs locally on windows

```console
cmd /c docs.bat
```

## Necessary packages on server-side
- Docker
- Python (> 3)
