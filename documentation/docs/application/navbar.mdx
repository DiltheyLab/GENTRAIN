# Navigationsleiste

Die **Navigationsleiste** ermöglicht Ihnen den schnellen Zugriff auf die verschiedenen Anwendungsbereiche von **GENTRAIN** sowie auf zentrale Funktionen wie das **Speichern und Importieren** der lokalen Datenbank (aktueller Zustand der Anwendung) oder den **Wechsel des aktiven Pathogens**.

## Elemente der Navigationsleiste

- **Dashboard:** Übersicht und Visualisierung der Daten
- **Ausbruchsanalyse:** Modul zur detaillierten Untersuchung von Ausbrüchen
- **Datenverwaltung:** Import von Fall-, Sequenz- und Kontaktdaten sowie Verwaltung und Einstellungen zur Datenspeicherung
- **Hilfe:** Zugriff auf Support-Informationen, Tutorials und Dokumentation

Auf der rechten Seite der Navigationsleiste befinden sich drei zentrale Aktionen:

- **Zustand importieren:** Laden Sie eine zuvor gespeicherte JSON-Datei, um Ihren lokalen Arbeitszustand wiederherzustellen.
- **Zustand speichern:** Exportieren Sie den aktuellen Anwendungszustand als JSON-Datei, um Ihre Arbeit zu sichern.
- **Pathogen-Auswahl:** Wählen Sie das Pathogen aus, für das Sie Daten importieren und analysieren möchten.

---

## Verwendung der Schaltflächen

### 🗂️ Zustand importieren

1. Klicken Sie auf **„Zustand importieren“**.
2. Wählen Sie die zuvor exportierte **JSON-Datei** aus.
3. Nach erfolgreichem Import erhalten Sie eine **Bestätigungsmeldung (Toast)**.  
   Anschließend werden die importierten Daten automatisch übernommen.

### 💾 Zustand speichern

1. Klicken Sie auf **„Zustand speichern“**.
2. Ihr Browser lädt eine **JSON-Datei** mit dem aktuellen Zustand herunter.  
   Bewahren Sie diese Datei sicher auf, um Ihre Arbeitsumgebung später wiederherstellen zu können.

### 🧫 Pathogen wechseln

1. Klicken Sie auf das **Pathogen-Menü** (rechts in der Navigationsleiste).
2. Wählen Sie das gewünschte Pathogen aus.

---

## Fehlerfälle & Tipps

- ⚠️ **Import fehlgeschlagen:**  
  Stellen Sie sicher, dass die Datei ein gültiges **GENTRAIN-Export-JSON** ist. Beachten Sie gegebenenfalls die Fehlermeldung in der Anwendung.

- 📁 **Exportdatei verloren:**  
  Ohne gespeicherte Export-Datei lässt sich Ihr individueller lokaler Zustand **nicht wiederherstellen**. Erstellen Sie daher regelmäßig Sicherungen Ihres Arbeitsstands.

---

> 💡 **Tipp:**  
> Nutzen Sie die Import- und Exportfunktionen regelmäßig, um Ihre Arbeitsschritte zu sichern und zwischen verschiedenen Sitzungen fortzusetzen.
